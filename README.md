# excel-financial-modeling
Simulador profissional de investimentos em Fundos Imobiliários (FIIs) desenvolvido no Excel. Interface em formato de aplicativo com projeção de patrimônio (função VF), alocação automatizada por perfil de investidor via chave composta (PROCV) e gráficos de rosca interativos. Modelo dinâmico voltado para portfólio de finanças e dados.
